# scrcpy server

`scrcpy-server` is the server of scrcpy v3.3.3, unchanged, from
https://github.com/Genymobile/scrcpy/releases/tag/v3.3.3
(SHA-256 7e70323ba7f259649dd4acce97ac4fefbae8102b2c6d91e2e7be613fd5354be0).
Running Devices pushes it to the device to stream the screen and inject input.
